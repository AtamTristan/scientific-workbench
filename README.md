# Scientific Workbench

Private-oriented visual scientific-programming environment. This first separated slice can export the WILD-GAD artifact locally or publish it through the Scientific Publication API.

```bash
npm ci
npm run dev
```

Open <http://127.0.0.1:5174>. FastAPI is expected at `NEXT_PUBLIC_SCIENTIFIC_API_URL`, defaulting to <http://127.0.0.1:8000>.
